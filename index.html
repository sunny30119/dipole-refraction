🔬 偶極與折射

光進入玻璃為什麼會「變慢」、會「轉彎」？

很多人會這樣想：

光的電場推動玻璃裡的電子雲
→
電子雲被推歪，形成偶極矩
→
偶極產生反向電場，把光「擋慢」
→
？？？（卡住）

前兩步是對的。第三步是靜電的想法（像電容器裡的介電質）。可是光的電場每秒翻轉約 500 兆次，電子會一直晃。一直晃的電荷會發射電磁波。所以正確的鏈是：

光的電場推動電子
（第 1 階）
→
晃動的偶極變成小天線，發出二次波
（第 2 階）
→
二次波與原本的波相加，波峰被往後拖
（第 3 階）
→
一層層累積，看起來速度變成 c/n
（第 4 階）
→
斜射時邊界依序被驅動，波前轉彎
（第 5 階）

每一階都是「預測 → 操作 → 解釋」：先做預測，動畫才會解鎖。

1　彈簧上的電子

電子被原子核拉住，就像掛在彈簧上的球。彈簧有自己最順的晃動節奏，叫「共振頻率 ω₀」。光的電場以頻率 ω 週期性地推它。

E：光的電場p：偶極矩（電子被推歪造成）
看解釋

ω 比 ω₀ 小（可見光打在玻璃）：彈簧來得及反應，電子跟著力同步晃。電子帶負電，所以電子往電場的反方向跑，但偶極矩 p 的方向（從負電指向正電）剛好和 E 同方向、同步。

ω 接近 ω₀：共振，晃得最大，而且 p 落後 E 約 1/4 拍。這時光會被大量吸收。

ω 比 ω₀ 大（例如 X 光）：電子太重、反應不過來，變成和力「反著」晃，p 和 E 反相。

玻璃中電子的共振頻率在紫外光範圍，所以可見光屬於第一種情況。這一點在第 3、6 階會用到。

先在上面做預測，動畫才會解鎖 🔒

2　晃動的偶極＝小天線

紅＝電場（上下方向的部分）和偶極箭頭同向，藍＝反向，白色代表電場為零。「晃動」畫面的顏色深淺經過調整以便觀察；真實的輻射電場強度隨距離 1/r 遞減。圖中只畫遠處的輻射場。

看解釋

靜止的偶極只在自己附近有電場，距離一遠就很快消失（約 1/r³），而且不會往外跑。這就是你原本想的「反向電場」。

一直晃的偶極會不斷往外送出波紋：它變成一支小天線，發出和光同頻率的電磁波，叫做「二次波」。

注意：沿著偶極晃動的方向（圖中的上下方向）幾乎沒有波發出來，最強的是垂直於晃動方向的地方。

所以問題不再是「反向電場會怎樣」，而是：幾十億支小天線發出的二次波，和原本的光加在一起，會變成什麼？→ 第 3 階。

先在上面做預測，動畫才會解鎖 🔒

3　兩波相加：延遲是怎麼來的 ⭐

光從左往右走。中間虛線是一「整片」薄薄的原子層（很多偶極排成一面牆）。

原本的光原子層發出的二次波兩者相加（實際測得的光）

⚠ a 被故意放大到看得見。真實的一層原子 a 極小，此時相加後的振幅幾乎不變（振幅變化是更高階的小效應），只剩下「延遲」。

看解釋

重點一：原本的光沒有消失。藍色波在原子層後面照樣用光速 c 往前走。

重點二：二次波比原本的光慢 1/4 拍。在很遠的地方看，一整片偶極加起來的電場，正比於「偶極變化的快慢」再加上一個負號。變化的快慢比偶極本身超前 1/4 拍，負號再翻半拍，合起來就是落後 1/4 拍。（詳見 Feynman 物理學講義第一冊第 30、31 章。）

重點三：大波 + 落後 1/4 拍的小波 = 往後退一點的波。綠色波峰落在藍色波峰的後面。這就是延遲。

切到「思考實驗：同步」看看：如果二次波和原本的光同步，相加只會讓波變大，波峰不會移動。所以延遲來自那 1/4 拍的時間差，不是來自「反向電場擋住光」。

切到「超前 1/4 拍」：電子反著晃（第 1 階的高頻情況），波峰往前跑，這就是 X 光在玻璃中折射率略小於 1 的原因。注意：n<1 只代表「波峰的位置」（相速度）跑得比 c 快，能量和訊息仍然不會超過光速。

往回走的二次波，疊起來就是反射光。反射和折射來自同一批偶極。

4　一層層累積：看起來變慢了

上排：只有真空的參考光。下排：同一道光穿過一塊由很多原子層組成的介質（灰色區域）。灰色虛線標出真空光的波峰位置，三角形標出實際的波峰。

⚠ 為了看得見，層數很少、每層延遲很大。真實玻璃每一層原子只造成極小的延遲，但一公釐厚就有數百萬層。

看解釋

在「逐層」模式仔細看下排的三角形：在兩層之間，波峰還是用光速 c 前進；每穿過一層，就被往後拖一點。

平均起來，波峰前進得比 c 慢。這個「波峰平均前進速度」叫相速度，就是 c/n。

讀數中的 n 是這樣算的：穿過厚度 L 的介質，總共延遲 N·a（弧度），所以 n = 1 + N·a ÷ (2π · L/λ)。

光穿出介質後，又恢復用 c 前進，但已經落後了一段，追不回來。

這也說明一個常見迷思是錯的：「光子被原子吸收、停一下再放出來，所以變慢」。實際上光從頭到尾沒有停，是波形被疊加一次次往後拖。

5　斜射：邊界上的波浪舞

左邊是空氣，右邊是介質。邊界上的圓點是偶極，顏色表示它此刻被推的方向。簡化：介質裡的小波直接用第 4 階得到的速度 c/n 前進（真實情況是每個小波在原子之間仍以 c 前進，是一層層偶極疊加後「整體」才等效成 c/n；這裡直接借用第 4 階的結論）。

紫色實線：入射光線與依 Snell 定律算出的折射光線。只畫往前進的光，不畫反射光。

看解釋

波浪舞：光斜斜打到邊界，邊界上的偶極不是同時被推，而是從上到下依序被推，像體育場觀眾做波浪舞。這個「依序」的節奏由入射光決定。

小波：邊界偶極發出的二次波進入介質後，又會一路被後面的原子層「拖慢」（第 4 階），所以整體等效為以 c/n 前進、波長變短。為了簡化，這裡直接讓小波用 c/n 前進；別因此以為原子之間的場是用 c/n 在跑。

轉彎：在「全部偶極疊加」模式中，右半邊的條紋完全是由邊界上的偶極加總算出來的，程式沒有事先畫好折射波。條紋會自動沿著紫色的 Snell 光線走。

在「小波作圖」模式中，橘色圓弧是每個偶極的小波波峰，綠色虛線是它們共同的包絡線，也就是折射波的波前。

把 n 調到 1：介質和空氣一樣，光不轉彎。把 θ₁ 調到 0：邊界上所有偶極同時被推，光也不轉彎。要轉彎，兩個條件缺一不可：斜射＋波長改變。

6　色散：為什麼三稜鏡會分出彩虹

折射率 n 與波長

三稜鏡（60° 頂角）

模型：單一共振的 Sellmeier 式 n² = 1 + B·λ²/(λ² − λ₀²)，B = 1.273。λ₀ = 100 nm 時，n(589 nm) ≈ 1.52，接近一般冕牌玻璃。三稜鏡圖依實際角度計算，沒有誇大。

看解釋

回到第 1 階：光的頻率越接近電子的共振頻率，電子晃得越大，二次波越強，延遲越多，n 就越大。

玻璃的共振在紫外光。藍紫光比紅光更接近紫外光，所以藍紫光的 n 比較大，在三稜鏡中偏折得比較多。

把 λ₀ 往可見光方向拉（例如 200 nm 以上），n 整體變大，而且紅、紫光的差距急速拉大：這就是高色散玻璃（如火石玻璃）的原理。

挑戰題：X 光的頻率比電子的共振頻率高很多，依第 1、3 階，X 光在玻璃中的 n 會大於 1 還是小於 1？（提示：第 3 階的「超前 1/4 拍」）

7　光到底有沒有變慢？

這一頁沒有用到 n。電腦只照兩條規則一格一格往下算：① 電磁波的規則（馬克士威方程）；② 每個電子都像彈簧上的球，被電場推著晃（第 1 階）。脈衝在介質裡變慢、波長變短、出現反射，全部是算出來的結果。

光的電場 E電子晃動 P（示意大小）▼ 脈衝能量最集中的位置

⚠ 模擬是一維的，參數選成 n = 1.50；電子的共振頻率設在光頻率的 3 倍（代表紫外光）。左右兩端會把波吸收掉，不會反彈。

看解釋

「光速」其實有三種，要分開講：

名稱是什麼在玻璃中
相速度波峰這個「花樣」前進的速度（第 3、4 階）c/n，決定折射角
群速度整個脈衝（能量、訊號）前進的速度（本頁的綠色三角形）比 c 慢，本頁約 c/1.60
最前緣脈衝最最前面、極微弱的一點點擾動永遠是 c

為什麼能量會變慢？看能量條：脈衝在介質裡時，有一大塊能量是暫存在電子的晃動裡（紅色）。電場把能量交給電子，電子在同一拍內又把能量交回來，像接力賽中一部分棒子永遠在跑者手上傳來傳去。任何時刻都有一部分能量「停」在電子身上，所以整體往前送的速度變慢了。

這和「吸收再放出」不一樣：電子沒有吸收一整份能量、等一段時間才放出來。它是和光同步連續晃動，每一拍都在收、也都在還。

把摩擦拉到 0：脈衝照樣變慢。所以變慢不是因為能量變成熱。摩擦只會讓光越走越弱（被吸收），對速度幾乎沒影響。

最前緣為什麼是 c？電子在光到達之前不會動，所以最前面那一點點電場前面沒有任何東西可以疊加，只能用 c 前進。之後電子開始晃、二次波才開始疊上去，波形才被拖慢。這一小段最前緣的波非常微弱（稱為「前驅波」），本模擬的格子太粗，算不出來。
